No lobbies yet. Host a game from the PC.
1 · Start the server
The Pi starts it on boot. Open http://cartslop.local:42777 from any device on the Wi-Fi.
2 · Host on the PC
In the game choose MULTIPLAYER → HOST. The game registers with the Pi automatically and shows a short room code.
3 · Friends join
Paste the 5-character room code in MULTIPLAYER → JOIN, or open BROWSE in the lobby. Traffic goes PC → Pi → friend.
Router note
For internet friends the Pi's ports must be reachable. UPnP is attempted automatically; otherwise forward TCP 42777 and UDP 42800–42819.
