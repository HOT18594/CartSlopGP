# Vehicle audio

Each playable vehicle has its own loop, loaded by `CartFeedback` from
`assets/audio/sfx/engines/`:

| Vehicle | Loop | Character |
| --- | --- | --- |
| Shopping cart | `cart_rattle.wav` | no engine; metal rattle + wheel squeak |
| Sedan | `sedan_loop.wav` | smooth 4-cylinder hum |
| Sports car | `sports_loop.wav` | high-revving, brighter harmonics |
| Taxi | `taxi_loop.wav` | rattly, lower diesel-ish tone |
| Van | `van_loop.wav` | mellow 6-cylinder |
| Box truck | `truck_loop.wav` | deep diesel chug, slow revs |
| Police cruiser | `police_loop.wav` | V8 burble + faint whine |

The bundled files are **original synthesized loops** generated by
`tools/gen_vehicle_loops.py` (CC0 / public domain, no attribution needed).
They are seamless 2-second loops and are pitch-shifted by speed at runtime.

## Free libraries used for research / optional replacements

All of these are free for commercial use. Check the individual licence on the
page before shipping a replacement.

- **OpenGameArt — Racing car engine sound loops** (CC0): six looping engine
  samples at different pitches. https://opengameart.org/content/racing-car-engine-sound-loops
- **OpenGameArt — Car engine start 01** (CC0): one-shot ignition.
  https://opengameart.org/content/car-engine-start-01
- **OpenGameArt — Motor Sound Effect** (CC0): loopable mouth-made motor.
  https://opengameart.org/content/motor-sound-effect
- **Freesound — Sedan engine loop** by Dmitry_mansurev64 (CC0):
  https://freesound.org/people/Dmitry_mansurev64/sounds/748027/
- **Freesound — Shopping cart wheels, medium speed** by SpliceSound (CC0):
  https://freesound.org/people/SpliceSound/sounds/218325/
- **Freesound — shopping-cart-rattle** by alienistcog (CC0):
  https://freesound.org/people/alienistcog/sounds/125161/
- **SFXMint — Squeaky Shopping Cart Rolling 06** (CC0, direct MP3/WAV):
  https://sfxmint.com/sounds/cart-wheels-rolling-06

## Swapping in a downloaded loop

1. Export/convert the clip to **WAV, mono, 44.1 kHz**, and trim it to a clean
   loop (2–6 s).
2. Overwrite the matching filename in `assets/audio/sfx/engines/`.
3. In Godot, set the WAV import option **Edit → Loop Mode → Forward**.
4. Re-export the game.

No code changes are needed; the catalog already points at these paths.
