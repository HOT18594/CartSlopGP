PATCH NOTES · 2026-11-25

WHAT'S NEW IN 0.8.7

A multiplayer-correctness, latency and load-time release. Same karts, same chaos — sharper under the hood and behind the wheel.

LATENCY

LAN races join direct

50–70 ms → 6–7 ms

Same-network players now try a direct ENet link before the relay. Behind the Pi's relay the round trip still dropped to ~27–34 ms, and TCP_NODELAY + keep-alive removed the hidden stalls.

FAIRNESS

One leaderboard for everyone

Host-authoritative standings

The host builds a single revisioned standings snapshot every client accepts in order. Finish times are RTT-compensated and ties break deterministically, so close racing ends identically on every screen.

PERFORMANCE

Up to 5× faster race loads

Stadium 10.8s → 2.8s

A bucketed centreline index makes nearest-point queries 13.5× faster, with a permanent spline-index audit proving the fast answer matches a brute-force scan on every map.

UI

100% black-slanted UI

All 56 screens audited

Every menu, pause screen, settings page and multiplayer end card now shares one crisp slanted dark-glass language — verified at 1280×720 and 1920×1080 with zero layout overflows.

THE GAME

BUILT FOR MAYHEM

01

Hop-drift & boost

Snap the cart sideways, land the drift and fire the twin thrusters. Weighty arcade handling with per-vehicle physics and a boosting ability dock.

02

Hero cart & paint shop

Race the coaxial twin-thruster Hero Shopping Cart or a Pro Racer, then take it to the 8-colour live paint shop before the race starts.

03

Living worlds

Seven themed ambient FX palettes — blizzard, sand, pollen, embers, sea mist and more — with quality tiers that keep a browser tab playable.

04

Six-track OST

Custom-mastered OGG tracks with a three-deck equal-power crossfade engine. Music never hard-cuts between menus, races and results.

05

Split-second feedback

Per-cart tyre marks, squash-and-stretch body roll, landing compression and springy suspension — purely visual, driven from replicated state.

06

Cross-platform

Windows, macOS (universal), Linux and Web from one Godot 4.7.2 project. The browser build auto-detects low-end hardware and trims itself.

ONLINE & LAN

Host a room, share a five-letter code, and friends are in — through the relay from anywhere, or straight across the home network. The Pi keeps the lobby and the scoreboard honest; every client renders the same authoritative result.
