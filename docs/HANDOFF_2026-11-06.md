## 2. What this session did, in order

### Pass 1 — animation, changelog, keyboard nav, loading bar, vehicle stats, multiplayer
- New `scripts/ui/ui_anim.gd`: shared eased fades/pops/slides/shakes and
  frame-rate independent `damp()`. All tweens use `TWEEN_PAUSE_PROCESS`.
- New `scripts/ui/menu_nav.gd` (**`MenuNav` autoload**): owns ALL arrow / WASD /
  d-pad / Tab focus. Builds a geometry-aware focus map, installs explicit
  `focus_neighbor_*` and `focus_next/previous`, wraps at edges, keeps focus out
  of hidden panels, and never steals letters from a `LineEdit`. Overlays join
  group `nav_scope`; the deepest visible one wins. Screens may expose
  `nav_horizontal(direction) -> bool` for left/right actions.
- `candy_button.gd`: focus now animates like hover; selector chevrons point
  **inward** (`>  <`), not outward. `ui_kit.gd` installs a yellow focus ring.
- `pill_cycler.step(dir)` lets left/right cycle BOTS/MODE in place.
- `changelog_panel.gd/.tscn`: anchored panel, scrollable text, **165-line
  budget** pagination (not release count), flush-left bullets that fold
  markdown soft-wraps. Hides PREV/NEXT and the hint when there is only one page.
- `loading_screen.gd` + `scene_loader.gd`: damped 10-section bar, cart at the
  fill head, fixed big percentage, no card.
- `stat_bar.gd` + `vehicle_catalog.stats_for/stat_ranges/stat_ratio`: 10-block
  garage-relative bars instead of raw numbers.
- `lobby_menu.gd/.tscn`: first rebuilt as two columns, then simplified (see pass 2).

### Pass 2 — lobby cleanup

## 6. Hard-won gotchas (do not relearn these)

1. **Godot 4.7 `Object.get_meta(key, null)` ERRORS** when the key is missing and
   the default is NIL. Always guard with `has_meta()`. Fixed in `ui_anim.gd`;
   audited project-wide, none remain.
2. **No `class_name` for new helper scripts.** The global class cache is not
   populated on a cold headless boot. Use `const Foo := preload("res://...")` in
   every consumer instead. Applies to `UiAnim`, `StatBar`, `ArtBackdrop`,
   `PlayCard` consumers.
3. **`set_anchors_preset(PRESET_FULL_RECT)` is not enough** for a Control
   parented to a plain Control — it stayed 0x0. `ArtBackdrop` now explicitly
   fits to parent size in `_process`. Containers resize children themselves,
   which is why the bug only showed on the menu shell.
4. **Overlapping translucent scrim bands** (`height/28 + 1.0`) produce visible
   horizontal stripes over flat AI art. Use exact float heights, many bands.
5. **Typed arrays cannot be assigned via `Object.set()`.** `RoomBrowser` exposes
   `set_rooms(rooms: Array)` for tests. Also `queue_free()` alone leaves
   children counted until end of frame — `remove_child()` first.
6. **`UiKit._style_node` forces every Button to 54 px tall** unless
   `custom_minimum_size.y >= 120` or the node has meta `skip_kit`. Setting a
   button's width works; setting its height does not stick.
7. **Pause menu script sits on `Root` (a Control), not the CanvasLayer** —
   paths are `$Center/Panel`, not `$Root/Center/Panel`.
8. **RichTextLabel does not render `[lb]`/`[rb]` reliably here.** Changelog
   escaping converts square brackets to parentheses.
9. **macOS**: a blanket `chmod -R` invalidates the ad-hoc code signature;
   `codesign --verify --strict` fails legitimately for ad-hoc bundles.
10. **Updater always quits the game** after launching the installer script. The
    old macOS branch skipped `get_tree().quit()` and hung forever.
11. `test_join_started.gd` is a LIVE-server test; it prints SKIP without `CODE`.
12. `--script` SceneTree tests still get autoloads in this project; tests
    referencing `Network` must run as `.tscn` if they need `get_tree()`.
