POLY HAVEN (Meadow Loop v2 realistic scenery)
---------------------------------------------
https://polyhaven.com - Creative Commons Zero 1.0 (CC0, public domain)
https://polyhaven.com/license
Full per-asset list: assets/models/polyhaven/CREDITS.txt
Summary: 1k CC0 PBR sets (leafy_grass, dirt_floor, bark_brown_02, pine_bark)
for the meadow ground, dirt track and tree trunks; leaf/fern/grass alpha
atlases from island_tree_01, jacaranda_tree, grass_medium_01 and fern_02;
five small scanned ground-cover glTF models (grass_medium_01/02, fern_02,
moss_01, dead_tree_trunk_02). Photogrammetry TREE meshes are NOT shipped -
they are 40-950 MB each. Realistic trees are built procedurally in Godot from
the CC0 bark and leaf textures.
Reproduce with downloads/fetch_polyhaven.py and
tools/build_foliage_atlases.py.

NATURE / ENVIRONMENT (Meadow Loop)
----------------------------------
Kenney "Nature Kit" 2.1 - https://kenney.nl/assets/nature-kit
License: Creative Commons Zero 1.0 (CC0, public domain)
Author: Kenney (www.kenney.nl)
Local license copy: assets/models/kenney_nature-kit/License.txt
Source zip kept outside the repo at CartSlopGP/downloads/kenney_nature-kit.zip
87 selected .glb models in:
  assets/models/kenney_nature-kit/Models/GLB format/
Includes 38 tree variants (default/oak/cone/fat/tall/thin/simple/detailed/
small/pine/plateau, plus dark and autumn versions), bushes, grass clumps,
wildflowers, rocks, stones, stumps, logs, mushrooms and a wooden fence.
The pack ships KHR_materials_unlit flat-colour materials with no external
textures; scripts/minigames/foliage_baker.gd bakes those colours into vertex
colours so thousands of instances render in ~75 MultiMesh draw calls.

FONTS
-----
Fredoka - https://fonts.google.com/specimen/Fredoka
License: SIL Open Font License 1.1
Copyright 2016 The Fredoka Project Authors
Local license: assets/ui/fonts/OFL-Fredoka.txt
Files:
  assets/ui/fonts/Fredoka.ttf          <- upstream variable font (kept for reference)
  assets/ui/fonts/Fredoka-Medium.ttf   <- static wght=500 instance, generated locally
  assets/ui/fonts/Fredoka-Bold.ttf     <- static wght=700 instance, generated locally
Why static instances: Godot ignores the OpenType variable weight axis in this
pipeline, so tools/build_ui_theme.gd needs real static files. They were produced
with fontTools.varLib.instancer (wdth pinned to 100, wght pinned to 500/700).
